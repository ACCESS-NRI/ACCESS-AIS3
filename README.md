# ACCESS-AI3 Wholle-Antarctic Ice Sheet Model Configuration

---
## About
Open community whole-Antarctic ACCESS configuration for the Ice-sheet and Sea-level System Model (ISSM) for the ACCESS climate model suite.

## Project status
🚨 **ACCESS-AI3 is in the initial development stage.** 🚨

We welcome any feedback and ideas! Let us know by submitting [issues on GitHub](https://github.com/ACCESS-NRI/ACCESS-AIS3/issues) or [joining our community](https://forum.access-hive.org.au/c/cryosphere/34).
