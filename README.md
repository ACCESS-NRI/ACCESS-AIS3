# ACCESS-AIS3

---
## About
Open community whole-Antarctic configuration for the Ice-sheet and Sea-level System Model (ISSM) for the ACCESS climate model suite.

## Project status
🚨 **ACCESS-AIS3 is in the initial development stage.** 🚨

We welcome any feedback and ideas! Let us know by submitting [issues on GitHub](https://github.com/ACCESS-NRI/ACCESS-AIS3/issues) or [joining our community](https://forum.access-hive.org.au/c/cryosphere/34).

## Documentation
The [development record](https://access-nri.github.io/ACCESS-AIS3/) remains the project website and landing page. Visit the [ACCESS-AIS3 documentation](https://access-nri.github.io/ACCESS-AIS3/documentation/) for the repository architecture, model workflows, and Gadi run guidance.
